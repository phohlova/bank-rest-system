# Система управления банковскими картами


RESTful API для управления банковскими картами, пользователями и финансовыми транзакциями. Приложение построено на **Spring Boot 3** с использованием **JWT-аутентификации**, **PostgreSQL** и **Liquibase** для миграций базы данных.

##  Технологии

### Backend
- **Java 17+**
- **Spring Boot 3.2.x**
- **Spring Security** (JWT аутентификация)
- **Spring Data JPA** / **Hibernate 6**
- **PostgreSQL 15+**
- **Liquibase** (управление миграциями БД)
- **Spring Validation** (валидация данных)

### Документация
- **SpringDoc OpenAPI 3** (Swagger UI)
- **OpenAPI 3.0** спецификация

### Инструменты
- **Maven** (сборка проекта)
- **Docker** & **Docker Compose** (контейнеризация БД)
- **Lombok** (уменьшение boilerplate кода)

##  Возможности

### Для пользователей
-  Регистрация и аутентификация по JWT-токену
-  Создание и управление своими картами
-  Просмотр списка карт с пагинацией
-  Фильтрация карт по статусу (ACTIVE, BLOCKED)
-  Переводы между своими картами (транзакционно)
-  Маскирование номера карты в ответах (безопасность)
-  CVV не передаётся в ответах API

### Для администраторов
-  Просмотр всех пользователей системы (с пагинацией)
-  Просмотр всех карт всех пользователей
-  Создание карт для пользователей (с автогенерацией номера/CVV)
-  Блокировка и активация пользователей
-  Блокировка и активация карт
-  Удаление карт

### Безопасность
-  Хранение паролей в хешированном виде (BCrypt)
-  Stateless JWT аутентификация
-  Ролевая модель доступа (USER, ADMIN)
-  Валидация всех входных данных
-  Централизованная обработка ошибок
-  Защита от SQL-инъекций (JPA/Hibernate)

##  Требования

Для запуска проекта необходимо:
- **JDK 17** или выше
- **Maven 3.8+**
- **Docker** и **Docker Compose**
- **PostgreSQL 15+** (если не используете Docker)

##  Быстрый старт

### Шаг 1: Клонирование репозитория
```bash
git clone https://github.com/yourusername/bank-rest-system.git
cd bank-rest-system
```

### Шаг 2: Запуск базы данных (Docker)
```bash
docker-compose up -d
```

Переменные окружения по умолчанию:
- Хост: localhost
- Порт: 5433
- База данных: bank_db
- Пользователь: postgres
- Пароль: postgres

### Шаг 3: Запуск приложения
```bash
mvn clean package
java -jar target/bank-rest-system-1.0.0.jar
```
